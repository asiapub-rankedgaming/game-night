Asia Pub: Game Night

Staff Guidelines & Event Monitoring

01

Event Coverage

  • Game Night will be held during the 4th week of every month.
  • Only games played within the officially announced event schedule will be counted.
  • Example schedule: 6:00 PM – 10:00 PM.
02

Event Basis

  • Game Night standings will NOT be based on the RGC ladder or overall MMR.
  • Only the player's performance during the official Game Night coverage will be considered.
03

Staff Monitoring

During the event schedule, staff should:

  • Monitor players participating in Game Night.
  • Record the players who are actively playing.
  • Record their relevant statistics.
  • Record the Game ID of their games.
  • Monitor which players are leading the event statistics.
04

Player Proof

For a game to be counted, the participating player must submit:

Post-game result/statistics screenshot
Game ID

Staff must verify the submitted screenshot and Game ID before recording the game as valid.

05

Final Results

  • Review all recorded games.
  • Verify submitted screenshots and Game IDs.
  • Count only games played within the official event schedule.
  • Determine the final standings based on the verified event statistics.
Staff Reminder

Only verified games and statistics will be included in the final results.
