Asia Pub: Game Night

Staff Guidelines & Event Monitoring

01

Event Coverage

  • Game Night is held during the 4th week of every month.
  • The official event time is 19:00–23:00 RMT.
  • Only games played within the officially announced event schedule are counted.
  • Players using non-SG bots may still participate. The channel uses SG Bot, but the event is open to all players.
02

Event Basis

  • Game Night standings are not based on RGC ladder rank or overall MMR.
  • Players are ranked by their total number of verified wins during the official event coverage.
  • The top 5 players with the most verified wins will be rewarded, respectively.
  • Each valid, verified win counts toward the player's total.
Key point: Staff should focus on verified wins, not total games played, ladder rank, MMR, or other statistics.
03

Staff Monitoring

During the official event schedule, staff should:

  • Monitor players participating in Game Night.
  • Record eligible games played during the official event hours.
  • Record the Game ID for each submitted game.
  • Check the submitted Ladder Link for verification.
  • Maintain each player's verified win total.
  • Monitor the current standings based on verified wins.
04

Player Proof & Verification

For a game to be counted, the player must submit:

  • Game ID
  • Ladder Link

Staff must verify that the game belongs to the official event period before recording the win as valid.

Important: Only verified games should be added to a player's win total.
05

Final Results & Rewards

At the end of the event:

  • Review all recorded games and submitted proofs.
  • Remove or exclude any game that cannot be verified.
  • Finalize each player's total number of verified wins.
  • Rank players according to their verified win totals.
TOP 1
Global Rank 300 — Asia NightStar + Room Champion
TOP 2
Global Rank 150 — RGC Player
TOP 3–5
Diamond Membership
For ties: The current event rules do not specify a separate tiebreaker. Refer any tied final standings to the event manager rather than applying an unannounced tiebreaker.
06

Staff Quick Reference

  • Coverage: 4th week of every month, 19:00–23:00 RMT.
  • Basis: Verified wins only.
  • Player proof: Game ID + Ladder Link.
  • Participation: SG Bot is used in the channel, but all players are welcome.
  • Ranking: Most verified wins = highest standing.
  • Rewards: Top 1, Top 2, and Top 3–5 receive the rewards listed above.
